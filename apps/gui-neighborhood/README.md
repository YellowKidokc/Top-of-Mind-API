# GUI Neighborhood

This folder is a local design archive for Top of Mind / FIS GUI work.

It collects prior GUI, HTML, AHK, React, and PWA prototypes from the related
D-drive projects so the next frontend can borrow the good parts without hunting
through every repo.

## Browse

Open:

```text
apps/gui-neighborhood/index.html
```

The index links to copied HTML/HTM files and points to:

- `gui-inventory.json`
- `gui-inventory.csv`

## Import Rules

Copied extensions:

```text
.html .htm .css .js .jsx .tsx .ts .ahk
```

Skipped common generated/dependency folders:

```text
.git node_modules dist build .venv __pycache__ vendor site-packages
```

this archive before commit.
